# Análisis de productos y devoluciones — ModaModerna

## Objetivo

Analizar las ventas de los productos de **ModaModerna, una empresa ficticia de moda**, para identificar qué productos generan más ingresos, comprobar si se cumple el principio de Pareto y analizar las devoluciones de los productos TOP.

## Preguntas de negocio

* ¿Qué productos generan más ingresos?
* ¿Qué productos forman parte del TOP 20 %?
* ¿Se cumple el principio de Pareto?
* ¿Qué productos TOP concentran más devoluciones?
* ¿Por qué se devuelven estos productos?

## Conclusiones

* Los ingresos totales son de **11.673.072,86 €**. Los **120 productos TOP**, que representan el 20 % del catálogo, generan **3.883.977,20 €**, un **33,3 % de los ingresos totales**.

* **No se cumple el principio de Pareto**, ya que el 20 % de los productos no concentra el 80 % de los ingresos. Los ingresos están más repartidos entre los productos.

* Entre los productos TOP, la **talla incorrecta** aparece como uno de los principales motivos de devolución.

* Esto puede indicar que **conviene revisar la información sobre tallas o el tallaje de los productos** para reducir este tipo de devoluciones.
