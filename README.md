# Análisis de productos y devoluciones — ModaModerna

## Objetivo

Analizar los productos de **ModaModerna, una empresa ficticia de moda**, para estudiar la contribución de los productos TOP a los ingresos y sus principales motivos de devolución.

## Preguntas de negocio

### 1. ¿Qué se vende?

Análisis general del catálogo y de las ventas para conocer los productos y categorías que comercializa ModaModerna.

### 2. ¿Cuáles son los productos TOP?

Identificación del **20 % de productos con mayores ingresos** para conocer qué productos tienen mayor peso dentro del negocio.

### 3. ¿Se cumple el principio de Pareto?

El principio de Pareto plantea que aproximadamente el **20 % de los productos podría generar el 80 % de los ingresos**.

En este caso, los **120 productos TOP**, que representan el 20 % del catálogo, generan **3.883.977,20 €**, un **33,3 % de los ingresos totales** (**11.673.072,86 €**).

Por tanto, **no se cumple el principio de Pareto**, ya que los ingresos están más repartidos entre los productos.

### 4. ¿Qué productos TOP concentran más devoluciones? ¿Por qué se devuelven?

Una vez identificados los productos TOP, se analizan sus devoluciones para detectar qué productos concentran más devoluciones y cuáles son los principales motivos.

Entre los motivos de devolución destaca la **talla incorrecta**.

Esto puede indicar una oportunidad para **revisar la información sobre tallas y el tallaje de los productos**, con el objetivo de reducir este tipo de devoluciones.
